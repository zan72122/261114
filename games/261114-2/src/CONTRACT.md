# ぐるぐる！すいとるサイクロンそうじき — 実装契約（司令塔が管理）

5歳の子が指1本で遊ぶ、文字のいらない 3D Web ゲーム。最終成果物は `index.html` 1 ファイル（three.js 同梱・外部読み込みなし）。
このファイルが全モジュール共通の約束。**自分の担当ファイル以外は編集しない**（`base.js` `layout.js` `template.html` `tools/` `CONTRACT.md` は司令塔のもの）。
約束を変えたい・足りないときは、勝手に変えずに最終報告に書く。

## お話（全体像）
昼のリビング。天井からくす玉が 3 つ吊ってある。
1. **まえ**: くす玉のひも（輪つき）を下に引く → パカッと割れて、紙ふぶき・紙テープなどが床に降る。カメラは降る紙を追って床へ下がる。
2. **まんなか**: 手前にキャニスター型のサイクロンそうじき。指で床をなぞると、ヘッドが指について動き、押している間だけモーターが回る。
   吸ったものはホースを通って**手前の大きな透明カップの中でぐるぐる回る**（これが主役）。指を離すとモーターが止まり、中身がふわっと底に落ちる。
   くつしたは大きすぎてヘッドに貼りつく（モーターが苦しそうな音）→ そのまま洗濯かごへ運ぶと、ぽとんと入る。
3. **あと**: 床がきれいになると、ごみ箱のふたが開く。透明カップを外してごみ箱の上へ運び、タップで底がパカッ → どさっ。
   1 つだけ引っかかって残る → とんとんで落ちる。カップを本体に戻すとカチッ。やさしいチャイム。次のくす玉へ。
   3 つ終わると夕方になり、朝になってくす玉が新しくなる（くり返し遊べる）。

## 見た目の方針（必須）
- **写実的な実際の 3D。「本物どおり、ふつうの見た目」**。おもちゃ風・ローポリ・絵本風・シュール・不気味は禁止。顔・目・キャラクター化は禁止。
- 実寸で作る（`layout.js` の `L`）。角は丸める（面取り）。素材は PBR（`MeshStandardMaterial` / `MeshPhysicalMaterial`）で、
  粗さ・金属感・うっすらした模様（Canvas で描く手続きテクスチャ）を持たせる。ベタ塗りの原色は避ける。
- 文字・数字・ロゴ・記号は一切描かない。
- 特定の実在製品の意匠は真似ない（色は 白 `0xf4f2ee`・ティール `0x1fa39a`・濃灰ゴム `0x2b2d30`・アルミ銀、解除ボタンはオレンジ `0xf08a24`）。

## 技術の約束
- three.js **r160**（`THREE` がスコープにある）。ライトは物理単位（`DirectionalLight` 強さ 2〜3.5、`HemisphereLight` 1 前後）。
  色テクスチャは `SRGBColorSpace`。レンダラは ACES トーンマップ + sRGB 出力（`Base.makeRenderer`）。`scene.environment` に `Base.makeEnv()` の環境マップが入る。
- 1 ファイル = トップレベルに **`const 名前 = (() => { ... return {...}; })();` を 1 つだけ**。import/export 禁止。他のトップレベル識別子を作らない。
  全ファイルは 1 つの関数スコープに連結される（`tools/build.mjs`）。`'use strict'` 下で動くこと。
- 外部リソース（URL・フォント・画像ファイル）禁止。テクスチャは `Base.canvasTex()` などで手続き生成。乱数は `Base.rng(seed)` で決定的に。
- `update(dt, …)` の dt は秒（呼び出し側で 0.05 以下に抑える）。**毎フレームの new（Vector3 等）を避け**、使い回す。
- 低負荷: `Base.quality.low === true` のときは影・細部を省けるようにする（init 時に見るだけでよい。途中切替は `applyQuality()` があれば呼ばれる）。
- 目安: Room ≤ 70 ドローコール / 7 万三角形、Vacuum ≤ 45 / 4 万、Jar ≤ 16 / 2 万、Debris ≤ 14。Canvas テクスチャは 1024² 以下を数枚まで。
- 影: 床に落ちる影は Room の太陽光（`castShadow`）1 灯だけ。各メッシュは `castShadow/receiveShadow` を適切に。小さい粒は影なし。
- 例外を外へ投げない（音・保存などは失敗しても黙って続ける）。`console.log` を残さない。

## 座標と配置
`src/layout.js` の `L` が唯一の正。+x=右、+y=上、+z=カメラ側。床 y=0。主な値:
カメラ `L.cam`（遊び中は位置固定で 42° 見下ろし）、遊ぶ床 `L.play`（台形）、ラグ `L.rug`、かご `L.basket`、ごみ箱 `L.trash`、
くす玉 `L.kusu`、本体 `L.canister`、透明カップ `L.jarMount`/`L.jar`、ホース口 `L.hosePort`、持ち手の立ち位置 `L.user`、ヘッド `L.head`。
カメラは `L.camPlay(aspect)` `L.camBefore(i, aspect)` `L.camDump(aspect)` `L.camJarClose(aspect)`（`{pos,target,fov}`）。

## 確認のしかた（各実装役の最小限の自己確認）
- 構文: `node --check src/<file>.js`
- 見た目: 自分用の起動スクリプト `src/preview/<name>.boot.js` を書き、
  `node tools/build.mjs --out preview/<name>.html --modules <name> --boot src/preview/<name>.boot.js` でまとめ、
  `node tools/shot.mjs preview/<name>.html <png> --w 390 --h 844 --wait 1500 [--eval "window.__dbg.xxx()"]` で撮って Read で見る。
  起動スクリプトでは `Base.makeRenderer` / `Base.makeEnv` / （Room 以外は）`Base.previewLights` を使い、カメラは `L.camPlay(aspect)` などを使う。
  状態を切り替える `window.__dbg` を用意してよい（確認用スクリプトの中だけ。本体モジュールには入れない）。
  ソフトウェア描画なので 1 枚 数秒かかる。**撮るのは明らかな破綻（真っ黒・部品のずれ・向き違い・ちらつき・コンソールエラー）を直すための数枚だけ**。
- テストスイート・テスト用の仕組み・追加の検証は作らない。スクリーンショットは一時フォルダへ（リポジトリに入れない）。git の操作（commit 等）はしない。

# モジュール API

共通: `X.init(ctx)` の `ctx = { scene, renderer, camera }`。`setGlow(name, a)` の a は 0〜1 の強さ（0 で消灯）。
光らせ方は各モジュールが自分でやわらかく明滅させる（周期 1.2 秒くらい。まぶしすぎない、世界になじむ光）。

## `Sfx`（audio.js）— 音。すべて Web Audio の合成音。素材ファイルなし
`init()` は最初のタッチで呼ばれる（何度呼ばれても安全・失敗しても投げない）。init 前や失敗時は全メソッドが何もしない。
| メソッド | 内容 |
|---|---|
| `init()` / `setActive(bool)` / `update(dt)` | 開始 / 非表示時に suspend・復帰で resume / 毎フレーム（なめらかな追従用） |
| `setMotor(speed, strain, rug)` | 毎フレーム。speed 0〜1（回転数。0 で無音）、strain 0〜1（くつしたが詰まって苦しい音: 音が高く・うなる）、rug 0〜1（ラグの上はこもった音） |
| `setRattle(a)` | カップの中でビーズがカラカラ（0〜1） |
| `setSlurp(a)` | 紙テープをつるつる吸い込み中（0〜1） |
| `setFringe(a)` | ラグの房がパタパタ吸われている（0〜1） |
| `tick(type)` | 1 個吸った: `'paper'`（シュッ）`'star'`（チッ）`'bead'`（コッ/カン）`'pom'`（ポフッ）。連続しても耳障りにならないよう内部で間引く・音程を少しずつ変える |
| `land(type, v)` | 床に落ちた（v 0〜1 の強さ）。ビーズはコツコツ、ポンポンはほぼ無音。内部で間引く |
| `kusuTouch()` / `kusuOpen()` | ひもに触れた（鈴がシャン）/ 割れた（木のパカッ + シャララン） |
| `sockStick()` / `sockDrop()` / `sockBasket()` | くつしたが貼りついた（ボフッ）/ 床に落ちた / かごに入った（ポスッ + 小さな「できた」音） |
| `jarRelease()` / `jarSet()` / `jarClick()` | カップを外した（カチャ）/ 床に置いた（コト）/ 本体にはめた（カチッ） |
| `lid(open)` / `hatch(open)` | ごみ箱のふた / カップ底のふた（パカッ・カチ） |
| `dump(amount)` / `shake()` / `plop()` | 中身がどさっと落ちる（0〜1）/ とんとん / 最後の 1 個がぽとっ |
| `chime(kind)` | `'clean'`（床がきれい: キラリン）`'round'`（1 回終わり: やさしい短いフレーズ）`'night'`（夕方: ゆっくりした子守歌風）`'morning'`（朝: 明るい短いフレーズ） |
| `hint()` / `powerDown()` | ヒント用のごく小さい音 / モーターが止まるヒューン（自動停止時） |
音量は小さめ・耳にやさしく（5 歳児）。モーター音は「本物の掃除機らしい」が長時間でも不快でないこと。

## `Jar`（jar.js）— 透明カップとその中身（主役）
ローカル座標: 原点 = 円筒の中心、**+Y = 上端（ふた・取っ手側）、−Y = 底（開閉する底ぶた）、+Z = 本体に載せたときカメラを向く側**。
半径 `L.jar.r`、長さ `L.jar.h`。−Z 側（下面）は本体の受け台に載るので、半径 + 1.5cm を超える出っ張りを付けない（+Y の端近くの吸気口の短い管だけ可）。
| メンバ | 内容 |
|---|---|
| `init(ctx)` | 生成。`Jar.object`（`THREE.Group`）を作るだけで scene には足さない（Vacuum / game が親を決める） |
| `object` | カップ全体。中身のメッシュもこの子（ローカル座標で動く） |
| `add(type, color)` | 1 個入ってくる。type: `'paper' 'star' 'bead' 'pom' 'streamer'`、color は 0xRRGGBB。吸気口から入り、渦に加わる。上限 220 個（超えたら古い紙から間引く） |
| `count()` / `fill()` | 個数 / 見た目の満杯度 0〜1 |
| `update(dt, motor, time)` | motor 0〜1（実回転数）。重力は `object` の世界姿勢から毎フレーム求める（傾けても・縦にしても自然に底へ落ちる） |
| `getRattle()` | ビーズのカラカラ度 0〜1（個数 × 速さ。音用） |
| `setHatch(open)` | 底ぶたの開閉（アニメつき） |
| `dump()` | 底ぶたが開いている前提で中身を落とす。各個は底から出て重力で落ち、カップ底から 0.32m 下で消える。そのとき `on.land(type,color)`。1 個だけ引っかかって残る（ポンポン > 紙テープ > 紙の優先）→ 残りが落ち切ったら `on.stuck()` |
| `shake()` | カップをとんと揺らす。引っかかった 1 個が揺れ、**2 回目**で落ちる → `on.land` → `on.empty()`。中身があるだけのとき（dump 前）は中身が跳ねるだけ |
| `on` | `{ land:null, stuck:null, empty:null }`（game が関数を入れる） |
| `state()` | `'normal' 'dumping' 'stuck' 'empty'` |
| `clear()` | 中身を即消去して `'normal'` へ |
| `setGlow(part, a)` | `'handle'`（取っ手: 運ぶヒント）`'button'`（底ぶたの解除ボタン: 押すヒント） |
中身の動き（ここが面白さの核。丁寧に）:
- motor が上がると、底の山から舞い上がって筒の中を**渦になって回る**。種類ごとに回り方が違う:
  紙=軽くて速い・ひらひら裏返る・筒全体に散る、星（ホイル）=きらきら反射、ビーズ=重い・外壁沿いを転がる・回り始めも止まるのも遅い、
  ポンポン=大きくてゆっくり・ぽよんと跳ねる、紙テープ=芯のまわりにらせんで巻きつく。
- motor が下がると減速し、振り子のように揺れながら「いま下になっている側」の底に山になって落ち着く（水平な表面の山。数が増えると山が高くなる）。
- 中央に金属メッシュの芯（シュラウド）。中身は芯と外壁の間を回る。回っているときは薄い空気の筋が見えてもよい（控えめ）。
- 透明な筒はポリカーボネートらしく（縁のハイライト・うっすら映り込み・ごく薄い色）。中身がはっきり見えることを最優先。

## `Vacuum`（vacuum.js）— そうじき本体・ホース・延長管・ヘッド
キャニスター型。本体は `L.canister` に据え置き（鼻先は −z）。大きな後輪 2 つ、前に小さなキャスター、電源ボタン、後ろに排気グリル。
透明カップは本体の前半分の斜めの受け台（45°）に載る。ホースは `L.hosePort` から出て延長管のグリップへ。
延長管は見えない持ち手 `L.user` の方へ傾く: グリップ = ヘッド + 持ち手方向 × `L.wand.reach` + 上 × `L.wand.gripH`。
| メンバ | 内容 |
|---|---|
| `init(ctx)` | 生成して scene に追加 |
| `jarMount` | `Object3D`。世界位置 `L.jarMount`、`rotation.x = -L.jarMount.tilt`。ここに Jar を載せると Jar の +Y が前上、+Z がカメラ側を向く |
| `attachJar(obj)` / `detachJar(obj, scene)` | obj を jarMount の子にして原点に置く / 世界姿勢を保ったまま scene の子に移す |
| `setHead(x, z, lift)` | このフレームのヘッド中心の位置（床上）。lift(m) だけ持ち上げる。延長管・グリップ・ホースが追従する |
| `getHeadYaw()` | ヘッドの向き（rotation.y）。ヘッドの前縁は持ち手と反対側 |
| `getMouth(out)` | 吸い込み口の中心（世界座標、床の高さ）を out(Vector3) に入れて返す |
| `update(dt, s)` | `s = { motor, strain, flow, time }`。motor で本体が細かく震える・電源ランプ。flow 0〜1（吸い込み中）でホースが小さく暴れる。ホースの物理もここ |
| `setGlow(part, a)` | `'head'`（ヘッド: つかむヒント）`'cradle'`（カップの受け台: 戻すヒント）`'power'` |
- ホース: 長さ `L.hoseLen` の蛇腹ホース。両端固定のロープ物理（verlet、床と衝突）で自然にたるむ・揺れる。毎フレームのジオメトリ再生成は避け、頂点バッファを書き換える。
- ヘッドには前を照らす LED ライト（発光する細い帯 + 床に落ちるやわらかい光の楕円。本物の SpotLight は使わない）。
- 受け台は Jar の下面（ローカル z < −0.05）だけを支え、Jar の見える側を隠さない。

## `Room`（room.js）— 部屋・光・くす玉・かご・ごみ箱・ラグ
| メンバ | 内容 |
|---|---|
| `init(ctx)` | 部屋一式と照明を scene に追加 |
| `update(dt, time)` | くす玉の揺れ・光の明滅など |
| `kusu[i]`（i=0,1,2） | `{ setPull(p), touch(), open(), isOpen(), reset(), setGlint(a), getRing(out), getBall(out) }` |
| `paintTrack(x0, z0, x1, z1)` | ラグの上でヘッドが (x0,z0)→(x1,z1) と動いた。毛並みに掃除機の跡が残る（進む向きで明るい/暗い筋。本物のじゅうたんと同じ） |
| `setFringe(hx, hz, suction)` | ヘッド位置と吸う強さ 0〜1。ラグ南端の房がヘッドの方へ吸い寄せられてパタパタする。戻り値 = いま揺れている強さ 0〜1 |
| `setGlow(name, a)` | `'basket'` `'trash'`（中からやわらかく光る + ふち） |
| `trash` | `{ setLid(open01), addFill(color), reset() }` ふた（目標値へなめらかに動く）/ 中のごみの山に色を 1 粒足す（山が少しずつ高くなる） |
| `setTime(t)` | 0 = 昼、1 = 夕方〜夜（窓の光が暖色で低く・弱く、フロアランプが灯る）。途中値も可。game がなめらかに動かす |
| `applyQuality()` | `Base.quality` を反映（影の有無など） |
- くす玉: 半径 `L.kusu.r` の紙張りの球（色 `L.kusu.colors[i]`、金は箔っぽく）。天井から紐で吊る。縦に割れ目。下から引きひもが下がり、先に木の輪と房（輪の高さ `L.kusu.ringY`）。
  `setPull(p)` p 0〜1: 輪が下がり（最大 14cm）、ひもが張り、球が少し沈む。0 に戻すとぷるんと戻る。`touch()`: 輪と球がぷるっと揺れ、割れ目から紙が 2〜3 枚こぼれる演出（見た目だけ）。
  `open()`: 上のちょうつがいで左右にパカッと開き、開いたまま揺れる（短い紙テープが数本ぶら下がる）。`reset()` で閉じた新品に戻る。
  `setGlint(a)`: 輪と房がきらっと光る・そっと揺れる（引くヒント）。`getRing(out)`: 輪の世界座標、`getBall(out)`: 球の中心。
- 部屋: 木の床（板張り・手続きテクスチャ）、無地の明るいグレージュのラグ（短い毛足・房つき）、奥にソファとクッション、白い壁と巾木、
  西側の窓から昼の光（床に窓の形のひだまり）、フロアランプ、北の壁に三角旗のガーランド（文字なし）、観葉植物。
  **床とラグは紙ふぶきが映えるよう落ち着いた色に**。遊ぶ床（`L.play`）の中には家具を置かない。
- 洗濯かご（`L.basket`、編みかご or 樹脂、上が開いている。中にくつしたが入るので底が見えること）、ペダル式ごみ箱（`L.trash`、ふたが奥ちょうつがいで開く）。

## `Debris`（debris.js）— 床の紙ふぶき・紙テープ・ビーズ・ポンポン・くつした
| メンバ | 内容 |
|---|---|
| `init(ctx)` | 生成して scene に追加 |
| `on` | `{ suck:null, land:null, sockStick:null, sockDrop:null, sockBasket:null }`。`suck(type,color)`: 1 個吸われた瞬間。`land(type,v)`: 床に落ちた |
| `burst(round, origin)` | くす玉 round(0,1,2) の中身が origin{x,y,z} から降り始める（下の表）。着地点は `L.randomPlayPoint` で先に決め、必ず `L.inPlay` の中に落ちる |
| `update(dt, head)` | `head = { x, z, lift, yaw, motor, mouth:Vector3, vx, vz }`。motor>0.25 で引き寄せ（`L.pullR`）・吸い込み（`L.suckR`）。くつしたが貼りついている間は吸えない |
| `remaining()` / `falling()` | まだ吸われていない数（空中 + 床。紙テープは 1 本 = 1）/ まだ空中の数 |
| `nearest(x, z, out)` | 床にある一番近い 1 個の位置を out{x,z} に。無ければ false |
| `setTwinkle(a)` | 残りの粒がきらっと光る（探すヒント。0〜1） |
| `slurp()` | いま紙テープを吸い込んでいる強さ 0〜1 |
| `stuckSock()` / `socksLeft()` | 貼りついているくつしたの番号（無ければ −1）/ まだかごに入っていない数 |
| `dropSock()` | 貼りついたくつしたを離す（ヘッドの前にぽとっと落ちる）→ `on.sockDrop(i)` |
| `sockToBasket()` | 貼りついたくつしたが `L.basket` の中へ弧を描いて落ちる → 入ったら `on.sockBasket(i)`。入ったくつしたはかごの中に見えたまま |
| `resetSocks(onFloor)` | true: 2 つとも `L.socks` の床に置く / false: 2 つともかごの中に入った状態にする |
| `spawnLast(origin, target)` | 終わりの演出: 紙 1 枚だけがゆっくりひらひら落ちる（床に残り、次の回で吸える） |

- 落ち方: 紙・星はひらひら舞って 1.5〜3.2 秒かけて落ちる。ビーズは速く落ちて跳ね、ころころ転がって止まる（`L.inPlay` の外へ出ない）。ポンポンはぽよんと弾む。
  紙テープはほどけながら降り、床でくるんと曲がった帯になる（長さ 0.6〜0.9m、幅 1.2cm、12〜16 節の鎖）。
- 吸われ方: 引き寄せ半径内の粒はヘッドへ滑り寄り（紙は立ち上がってひらひら、ビーズは転がる）、吸い込み半径で口へ吸い込まれて消える。
  紙テープは端が口に入ると、**めんのようにつるつるっと吸い込まれる**（鎖を先頭から引き込む。ヘッドを動かすと残りがついてくる）。1 本吸い終わると `on.suck('streamer', color)`。
- くつした（子ども用・しま模様、長さ約 18cm、布らしい厚みと影）: motor>0.5 のヘッドが 0.15m 以内に来ると貼りつく（`on.sockStick(i)`）。
  貼りついている間はヘッドの前縁に半分吸い込まれてバタバタ震える。離した後 0.6 秒は再び貼りつかない。
- 描画は InstancedMesh（種類ごと）。粒の影は付けない（接地感は薄い影の丸などで安く出してよい）。
