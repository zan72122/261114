# ぐるぐる！すいとるサイクロンそうじき（gf-261114-nx2）

## 起動方法
- `index.html` を開くだけ（file:// でも Pages のサブフォルダでも動く。1 ファイル完結・外部読み込みなし・約 0.95MB）。
- 作り直すとき: `node tools/build.mjs`（`vendor/three` + `src/*.js` + `assets/` を `index.html` にまとめる開発用。実行時ビルドは不要）。

## お話と操作（指 1 本）
1. まえ: くす玉のひもを下に引く → パカッと割れて紙ふぶきが降る（カメラが床へ下がる）。
2. まんなか: 床をなぞるとヘッドが指についてくる。押している間だけモーターが回り、吸ったものが手前の透明カップでぐるぐる回る。離すと底に落ちる。
3. あと: ごみ箱のふたが開く → カップを運ぶ → タップで底がパカッ → 1 個残る → とんとん → 本体に戻すとカチッ。次のくす玉へ。3 つ終わると夕方 → 朝でくり返し。

発見: 種類ごとに回り方と音が違う（紙・ホイルの星・ビーズ・ポンポン）／紙テープはめんのようにつるつる吸える／くつしたは貼りつくので洗濯かごへ運ぶ／
ラグに掃除機の跡が残る・房が吸われてパタパタ／カップを押さえると渦をアップで見られる／ごみ箱の中が回を追って色とりどりに増える。

## 確認したこと（390×844、ヘッドレス Chromium）
- 読み込み・開始時のコンソールエラー 0。
- お話を通しで 1 周（くす玉 → そうじ → くつした → ごみ捨て → 戻す → 次へ）、および 3 つ目 → 夕方 → 朝 → 最初に戻るまで。エラー 0。
- 各段階の「次の 1 操作」の手がかり（輪のきらめき、粒のきらめき、かご・ごみ箱・受け台の光、放置時の半透明の指のお手本）が画面内に出ることを確認。

## 既知の問題・未確認
- 実機（iPhone / iPad）と音は未確認（音は合成音。ヘッドレスでは鳴らせないため耳での確認はしていない）。
- 横画面・iPad サイズは構図を自動で合わせる作りだが、画面での確認はしていない。

- 夕方の場面は露出を下げているだけなので、そうじきの写り込みは昼のまま少し明るい。
- 保存は「何個目のくす玉か」だけ。途中で閉じると、その回の最初（くす玉を引くところ）から。
