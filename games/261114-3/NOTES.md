# カタカタ！ミシンでつくるおでかけバッグ（261114-3）

識別子: gf-261114-nx3

## 起動方法
- `index.html` をそのまま開く（file:// でも Pages のサブフォルダでも可）。1ファイル完結・オフライン・外部読み込みなし。
- 作り直すとき: `npm install` → `node build.mjs`（`src/` と three.js を `index.html` に埋め込む開発時ビルド。実行時ビルドは不要）。

## お話と操作（指1本）
布を半分に折る → りんごを入れて持ち手を持ち上げると、あいた横からころん → ミシンで片側を縫う（布を針のほうへ押す）→ こんどは反対側からころん → もう片側も縫う → 落ちない＝バッグ完成 → ボタンをつけ、すいとう・おべんとう・ハンカチを入れる → 持ち上げて公園へ → 中身を出してピクニック → おうちの壁に完成バッグが並び、次の柄の布が出る。

発見: 折ると柄が表に出る／縫い目は指のぶれどおりに残る／糸巻きをさわると糸の色が変わる／はずみ車で1針／缶からボタンが出てくる／柄は4種類が順に出て、完成品は壁に3つまで残る。

## 確認したこと
- 390×844 で読み込み・開始時にコンソールエラーなし。お話を最初から次の周の始まりまで1回通し、各段階で「次の1操作」が画面内の合図（光・ゆれ・光の輪、放置で指のお手本）で示されることを画面で確認。
- 自動操作のブラウザ（ソフトウェア描画）での確認のみ。実機（iPhone / iPad）と音の聞こえ方は未確認。

## 既知の問題
- 持ち上げてりんごが転がる演出（約2.5秒）の途中で指を離すと、演出が終わるまでバッグが宙に残る。
- 缶から追加で出したボタンは、バッグに付ける前に再読み込みすると消える（付けたボタンは残る）。
- 縦持ちの電話では机全体が小さめに映る。縫う場面と持ち上げる場面は寄る。
- 横向きは一部の場面しか見ていない。
- 木目・布・背景はすべてコード内の手続き生成（外部素材・外部AIなし）。
